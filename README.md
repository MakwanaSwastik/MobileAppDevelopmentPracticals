# Mobile App Development Practicals

This repository contains a collection of practical projects and assignments focused on Android Studio and mobile application development. Each practical showcases various fundamental concepts and functionalities using Kotlin.

---

## Repository Overview

### [Assignment 1: Basic Concepts of Android Studio and Mobile App Development](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/Assignment1)

- **Description**: This assignment provides a foundational understanding of Android Studio and mobile application development in Kotlin. It covers essential concepts and introduces development tools, creating a base for advanced practices.

---

### [Assignment 2: Tic Tac Toe Game](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/Assignment2)

- **Description**: TicTacToeGame is a simple Android application designed for playing the classic game of Tic Tac Toe. It features a user-friendly interface that allows two players to take turns placing X and O symbols on a grid. The app includes functionality to reset the game and return to the home screen.

---

### Practicals

The practicals in this repository demonstrate various concepts of Android development using Kotlin. Each practical is distinct and focuses on different aspects of mobile application development.

---

### [Practical 1: Fundamentals of Android Development](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/P1)

- **Description**: This practical contains Java programs demonstrating fundamental concepts of Android Studio and mobile application development. Written entirely in Kotlin, it showcases various functionalities and basic development practices.

---

### [Practical 2: Android Activity with Lifecycle Demonstrations](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/P2)

- **Description**: This practical focuses on creating an Android Activity that displays a "Hello World" message. It demonstrates the Android Activity Lifecycle through Log messages, Toasts, and Snackbar messages, providing insights into activity states and transitions.

---

### [Practical 3: ConstraintLayout UI](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/P3)

- **Description**: This practical emphasizes creating a user interface using ConstraintLayout in Kotlin. It showcases how to create dynamic and responsive UIs for Android applications using constraints.

---

### [Practical 4: Login and Registration Activities](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/P4)

- **Description**: This repository contains two activities, `LoginActivity` and `RegistrationActivity`. Each activity uses a different layout and navigates between them using explicit intents, demonstrating navigation and data handling.

---

### [Practical 5: Implicit Intent Demo](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/P5)

- **Description**: Demonstrates the use of implicit intents in Android applications. Features include making calls, opening web URLs, accessing the gallery, and using the device’s camera—all implemented in Kotlin.

---

### [Practical 6: MP3 Player Application](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/P6)

- **Description**: An MP3 player application built using a service to play audio files in Kotlin. It demonstrates the integration of media playback functionality in Android applications.

---

### [Practical 7: Video and YouTube Player Application](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/P7)

- **Description**: This practical focuses on creating a video and YouTube player application. MainActivity hosts a VideoView, and YouTubeActivity features a WebView, switching between them using explicit intents.

---

### [Practical 8: Alarm Application](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/P8)

- **Description**: Demonstrates creating an Alarm application using Kotlin. It includes a service and BroadcastReceiver to handle alarms and play sounds.

---

### [Practical 9: Frame by Frame and Twin Animation](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/P9)

- **Description**: This practical illustrates frame-by-frame and twin animations in Android applications. It includes a splash screen demonstration with animations for edge-to-edge content display.

---

### [Practical 10: Contact Management and Map Display](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/P10)

- **Description**: An Android application for managing contact information using JSON data and displaying it in a RecyclerView. Additionally, it integrates Google Maps to showcase contact locations.

---

### [Practical 11: SQLite and JSON Data Retrieval](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/P11)

- **Description**: This application fetches JSON data, stores it in a SQLite database, and displays it in a RecyclerView. It includes functionality for viewing details on Google Maps and deleting data.

---

This repository serves as a guide for understanding and developing various Android applications using Kotlin, demonstrating key concepts and features in mobile application development.
