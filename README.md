# Mobile App Development Practicals

This repository contains a collection of practical projects and assignments focused on Android Studio and mobile application development. Each practical showcases various fundamental concepts and functionalities using Java.

## Repository Structure

- **Assignment 1**: 
  - Contains basic concepts of Android Studio and mobile app development. 
  - Link: [Assignment 1](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/Assignment1)

- **Assignment 2**:
  - TicTacToeGame: A simple Android application for playing the classic Tic Tac Toe game.
  - Link: [TicTacToeGame](https://github.com/MakwanaSwastik/MobileAppDevelopmentPracticals/tree/main/Assignment2)

- **Practicals**:  
  The practicals demonstrate various Android concepts. Each practical is distinct and not part of any assignment.
